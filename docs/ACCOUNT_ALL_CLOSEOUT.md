# 账号分析范围

分析按明确选择的游戏账号展示，不自动合并多个账号。不同账号的保底、时间线和资源不能直接共用，混合统计容易造成误读。

## 当前保留

- 同一账号内的“全部卡池总览”继续保留；快照保留限定／附加／武器／常驻筛选，筛选只影响当前账号统计和时间线。原发布记录的 schema 3 已由个人分析 schema 5 接续，部署要求见 Worker 指南。
- 模拟器继承只使用明确选中的账号及区服。专用 `mode=simulator-inheritance` 读取匹配修订的状态和该账号完整紧凑历史，保留免费／情报书／赠送用于查看、统计和导出；普通 `mode=analysis` 不附带继承历史。
- 切换游戏账号读取对应本地模拟存档，不合并多账号状态；游客的本地历史也通过相同投影继承。完整账号键解决同 UID 多区服的归属，无法确定区服时要求先选择。
- 导出弹窗中的“所有账号记录”继续保留，用于显式导出原始记录。
- 没有选中账号时，分析页回退到一个有效账号，不再隐式合并多个账号。

模拟器保存与历史继承的细节见 [模拟器合同](SIMULATOR_ENGINE.md)，个人快照部署见 [Worker 指南](PERSONAL_ANALYSIS_WORKER.md)。

## 导入数量与账号删除

文件识别数量、服务器确认的保存数量，以及当前账号／区服／卡池筛选的总览抽数分别核对。分析页读取快照，本机 `history` 可以只有部分明细或为空；这不表示服务器没有记录，也不能据此跳过文件待保存内容或禁用删除入口。

2026-10-17 起，文件保存先核对服务端完整历史，失败可保留预览继续；设置删除入口同时使用账号快照中的 `recordCount`。B 服与官服使用不同账号作用域，同 UID 不自动合并。详细进度和旧重复记录处理见 [文件导入恢复](FILE_IMPORT_RELIABILITY.md)；个人补录的已知下限与未知总量见 [个人补录分析](PERSONAL_MANUAL_ANALYSIS.md)。

## 当前关闭

- 未选账号时的跨账号 merged analysis。
- 多账号合并后的当前保底、软保底概率、平均 UP 和资源口径。
- 把“全部账号”作为默认分析状态展示给用户。

## 重新开放条件

重新开放跨账号汇总前，必须先定义并测试以下契约：

- 哪些指标可以聚合：总抽数、按卡池计数、按稀有度计数。
- 哪些指标必须隐藏或改名：当前保底、软保底概率、资源余额、抽卡计划。
- 时间线如何展示账号来源、排序和重复记录。
- 分享图、导出、桌面端和移动端是否使用同一套文案与字段。
- 旧导出和 BOT 文案不能把原始记录导出误称为分析汇总。
