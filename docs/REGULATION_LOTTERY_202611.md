## 内容与样式

`shared/regulationLottery.js` 保存本期公开配置与公开环境变量映射；`src/lottery/` 保存主题组件和样式。构建脚本在固定版本的 `open-lottery` 上接入这些文件，重新安装依赖后仍可完整构建，不需要提交或修改独立模板仓库。

本期使用深色背景、青绿边框、橙红几何背景、协议标记和建筑剪影。主题仅在当前活动 ID 匹配时启用，往期归档继续使用原样式。奖品原图保存在 `src/assets/lottery/regulation-developer-pack.jpg`；用户提供的图示及链接是同一件奖品，页面仅配置一项。

标题、正文、数字和报名表单统一使用 Adobe 思源黑体简体中文可变字体 2.005R。字体与 SIL Open Font License 保存在 `src/assets/fonts/source-han/`，随本期活动部署；浏览器已验证实际使用 `Source Han Sans CN VF`。

报名沿用上期的主站登录、领奖 QQ、实际加入 QQ 群 `1080983185`、机器人验证及首次通知后 7 日内回复要求。没有增加付费资格或新的奖品档次。奖品计划必须显式使用 `{"first":1,"second":0}`，遗漏 `second` 会触发原开奖函数的旧默认值。

主站社区区块在活动期间默认展示本期宣传卡，仍可切换社区与版本导览；截止后隐藏报名推广。抽奖页发现有效主站会话时自动建立独立活动会话，不要求重复登录。前端依照公开接口的认证状态和用户 ID 判断，不依赖不会返回浏览器的内部会话 ID；身份仍由服务端 Cookie 核验。主站和备用域名各自在当前受信任域名内完成 SSO 与回调，保留仅限当前域名的 Cookie 和同源写请求校验。

在主仓库运行：

```powershell
npm run lottery:build

```

访问 `http://127.0.0.1:4177/lottery/`。预览返回本地准备中活动，不连接生产登录、报名、联系方式和开奖接口。报名表单通过浏览器中的本地测试数据验证，不生成真实参与记录。
