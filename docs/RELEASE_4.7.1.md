# v4.7.1 发布记录

代码版本为 `4.7.1`，界面版本为 `v4.7.1`，构建标识为 `Build 2026.11.07`。本次更新集中于国服扫码导入、导入窗口和读取完整性。

## 功能与修复

- 国服官方导入新增扫码方式。站内登录后生成二维码，手机确认后选择游戏角色与区服，再进入既有导入流程。Token 与文件导入继续保留，国际服沿用原有方式。
- 统一扫码与 Token 登录窗口、账号确认和处理进度，改善手机排版、深浅主题提示及仅有一个角色时的确认交互。
- 浏览器仅保留本站随机设备标识，不保存官方登录凭证。扫码会话限本次使用，取消、离开及到期会清理；清理不等于官方账号退出或撤销其他设备授权。
- 共享请求工具增加超时与取消传播，限制结果不明确的写请求重放；目录和暂存记录完整分页，并校验数量与顺序，避免把截断结果当作完整内容。
- 文件导入保留缺名站内备份的已知字段，区分账号与区服，不推测缺失对象；相关修复沿用此前主线提交。
- 国服导入提前拦截缺少游戏角色的账号；跨区转发的响应体读取异常返回统一错误。跨区网络故障仍需按实际连通性处理。

## 发布顺序与服务边界

先在当前国服运行镜像上叠加扫码模块和必要接线，保留已有空角色校验、转发错误处理及运行配置，再推送主线触发前端部署。完整私有服务包、运行配置和凭据不进入公开仓库。

扫码要求站内认证，临时会话绑定用户；账号身份与设备上下文由服务器验证，随导入任务加密保存，角色改变时停止导入。二维码只在现有单进程国服服务内暂存，服务重启会使未完成扫码失效。此版不提供长期记住官方登录状态。

前后端检查完成后执行 `2026110705_release_471.sql`，同步运行版本、构建信息、双语公告和公共缓存版本。公告采用固定 ID 与既有连续段落格式，保留历史公告；重复执行不会生成重复公告，也不会重写原发布时间。此迁移不修改用户抽卡历史或导入任务。

## 验证与回退

功能提交已通过 12 个相关测试文件、191 项测试、目录归并验证及主站／抽奖子应用生产构建。发布时另核对版本清单与界面构建标识、公告重复执行、旧公告保留和公开基线一致性；扫码服务需覆盖会话鉴权、凭证不回传、任务加密交接、角色核对及手动 Token 路径。

上线前保存国服原镜像、受影响源码与 compose，以及公告和相关配置。部署后核对健康、完整导入、扫码鉴权边界与前端资源版本，公告发布后核对双语正文与公共接口。未自动执行真实账号扫码确认或用户历史写入来验证发布。

需回退时恢复国服原镜像和 compose，使用新的代码回退提交，并按备份恢复运行版本或停用本次公告；不回滚用户历史，不重复运行已应用的数据失效迁移。
