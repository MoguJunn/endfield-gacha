# 卡池目录保存与统计更新

卡池使用 `pool_id` 关联历史，名称、英文名称、描述和图片属于展示字段。修改展示字段只刷新目录缓存，不重新扫描历史、不重建相同名单，也不增加个人分析和公共统计版本。读取已完成快照时，接口按 ID 更新明确的展示字段，保留统计值、角色名称和计算时间。

真实名单、UP、卡池类型、开放顺序及继承规则改变时，按相关卡池、账号和跨池依赖更新统计。新增没有历史的限定期次仍需刷新相邻卡池，重构角色池需要覆盖同系列依赖。公共总览与排名会按实际输入变化刷新，但不会因此标记全部卡池与用户重算。身份或可见性变化仅重新核对相关池的可信抽数，组合抽数由成员计数汇总。

`2026101408` 保证更新语句兼容数据库更新保护，并跳过未变名单；`2026101409` 收敛目录与名单的统计依赖；`2026101410` 修正名单触发器局部变量 `id` 与真实 `pools.id` 的歧义；`2026101411` 提供公开统计 worker 所需的账号依赖、历史分页、版本读取和刷新调度合同。已提前执行过迁移的实例不要重跑旧迁移，先核对函数定义与执行记录。`2026101411` 可以覆盖较早的统计运维部署，保留现有快照和租约。

公开部署按数据库、统计 worker、网站读取接口的顺序升级。当前网站统计格式为 `public-statistics-v6`，worker 的 `STATISTICS_SNAPSHOT_SCHEMA_VERSION` 必须与读取接口一致；独立 worker 运行旧网站时可以明确配置旧格式，不能把切换网站域名当作 worker 已同步。卡池展示投影本身不要求重算已完成快照。

官方 ID 归并需保留旧 ID 别名、名单、武器与角色池关联及版本配置。存在正式历史时必须使用既有受控迁移路径，并核对抽数与记录身份。名称相同只能作为核对线索，不能单凭名称自动合并不同期次。

运行 `npm run test:pool-catalog:sql` 使用本机隔离 PostgreSQL 验证真实保存、ID 归并、名单变化、分类变更、空池继承、手工排除和权限。测试包含真实 `pools.id` 列，先复现旧触发器的 42702 错误和完整回滚，再验证修复后的行为。该测试不读取应用环境变量或连接生产；CI 同时执行完整公开基线验证。
