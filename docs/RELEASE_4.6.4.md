# v4.6.4 更新与发布准备

代码版本 `4.6.4`，构建标识 `Build 2026.10.09`。本次更新包含仓库整理、公开文档改进和本地预览修复，等待版本 PR 合入及部署；本文记录本地验证，不表示生产已升级。

## 功能与修复

- 访问验证隐藏“旧版验证”按钮，保留内部验证码实现，当前 Turnstile／PoW 切换继续可用。
- 开发与构建预览的 API 环境按项目目录加载，修复从其他目录启动时误读配置，导致卡池为空、统计返回 503 的问题。
- 贡献者内容沙盒补齐单池、五类合池与个人统计，复用演示历史和现行算法，不请求私有 API。目录修订后刷新本地结果，账号区服保持隔离。

## 仓库与文档

移除已废弃组件、旧管理函数、邮件模板和部署脚本；一次性报告转为本地产物，旧种子仅保留 ID 对照用途。完整迁移来源、许可证、共享导入合同和客户端兼容入口继续维护。

PostCSS 处理并入 Vite，Tailwind 主题在 CSS；Prettier 选项并入 package，测试初始化放入 tests。各工具仍保留需要的独立入口，详见 [仓库结构](REPOSITORY_LAYOUT.md)。

README、贡献指南、文档导航和 PR 模板按用户／贡献者用途整理。公开专题保留配置、接口、安全和数据合同，精简内部实施流水；历史发布记录继续注明对应版本。

## 本地验证

- 292 个测试文件、1,583 项单元测试通过，覆盖环境目录、统计、沙盒隔离和既有功能。
- ESLint、15 项公开验证脚本、193 迁移 baseline 校验通过；主站与抽奖子应用完整构建通过。
- 浏览器检查覆盖 11 个桌面、16 个移动（含兼容路径）与 7 个独立／开发入口，验证页面渲染及游客权限。
- 20 个双端沙盒登录页面通过；演示登录、个人／合池统计、公告保存及刷新保持验证通过，没有私有 API 或真实写入请求。
- 单池及五类合池真实公开快照成功读取，理论／概览切换、模拟器单抽与新旧主页切换通过；生产构建的主要页面与抽奖入口正常加载。

真实密码／OAuth 登录、官方记录获取、邮件投递、开奖和生产用户数据写入需要各自环境及操作验证，本次未执行。移动模拟器仍提示使用桌面版，首次指南仍是开发预览，未作为新增完整功能发布。

## 发布要求

版本 PR 合入后检查 CI、目标部署与正式域名。站点优先显示 `site_config.site_version`，应用包版本只作默认值；发布时同步运行时 `site_version`、`build_info` 和公共缓存版本，再核对页面显示。

本更新没有新增数据库结构迁移，不重复执行基线或历史日期／赠送修复。独立日历、记录获取后端与邮件服务器不从主站包版本推定升级。
