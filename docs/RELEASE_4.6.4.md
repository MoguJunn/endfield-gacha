# v4.6.4 更新与发布准备

代码版本 `4.6.4`，构建标识 `Build 2026.10.09`。本次更新包含模拟器引擎重写、仓库整理、公开文档改进和本地预览修复，等待版本 PR 合入及部署；本文记录本地验证，不表示生产已升级。

## 功能与修复

- 模拟器使用共享纯函数引擎，统一初始化、继承、切池与刷新；修复零抽限定池漏用共享水位，区分单池目标保障与重构系列状态。
- 继承保留全部真实历史，免费／情报书／赠送标记、统计与导出不丢失；专用接口只读取最新匹配快照，日常分析不附带完整继承历史。
- 资源与配额改为增量结算，模拟结果和存档单事务保存；已知旧存档迁移到 IndexedDB 并保留原数据，竞争或存储失败明确提示。
- 免费十连采用独立展示序号，保底分布使用实际水位；情报书和免费奖励分别记录获得／使用，防止重复领取。桌面界面、动画、分享与资源操作继续保留，详见 [模拟器合同](SIMULATOR_ENGINE.md)。
- 访问验证隐藏“旧版验证”按钮，保留内部验证码实现，当前 Turnstile／PoW 切换继续可用。
- 开发与构建预览的 API 环境按项目目录加载，修复从其他目录启动时误读配置，导致卡池为空、统计返回 503 的问题。
- 贡献者内容沙盒补齐单池、五类合池与个人统计，复用演示历史和现行算法，不请求私有 API。目录修订后刷新本地结果，账号区服保持隔离。

## 仓库与文档

移除已废弃组件、旧管理函数、邮件模板和部署脚本；一次性报告转为本地产物，旧种子仅保留 ID 对照用途。完整迁移来源、许可证、共享导入合同和客户端兼容入口继续维护。

PostCSS 处理并入 Vite，Tailwind 主题在 CSS；Prettier 选项并入 package，测试初始化放入 tests。各工具仍保留需要的独立入口，详见 [仓库结构](REPOSITORY_LAYOUT.md)。

README、贡献指南、文档导航和 PR 模板按用户／贡献者用途整理。公开专题保留配置、接口、安全和数据合同，精简内部实施流水；历史发布记录继续注明对应版本。

## 本地验证

- 最终 299 个测试文件、1,678 项单元测试全部通过，无未处理异常；覆盖引擎规则／独立概率公式、事务冲突与回滚、旧存档、游客／跨区服继承和服务端合同。
- ESLint、15 项公开验证脚本通过，baseline 已包含 194 迁移；最终主站与抽奖子应用完整构建通过。
- 浏览器检查覆盖 11 个桌面、16 个移动（含兼容路径）与 7 个独立／开发入口，验证页面渲染及游客权限。
- 20 个双端沙盒登录页面通过；演示登录、个人／合池统计、公告保存及刷新保持验证通过，没有私有 API 或真实写入请求。
- 单池及五类合池真实公开快照成功读取，理论／概览切换、模拟器单抽与新旧主页切换通过；生产构建的主要页面与抽奖入口正常加载。
- 重写后的浏览器验证覆盖全部演示历史继承、零抽池共享水位、刷新、情报书与免费十连、正常／跳过动画、两页面修订竞争、JSON 导出、资源开关、双语、PNG 分享和重置，未请求私有 API。
- 隔离 PostgreSQL 17 验证 schema 3 重建、旧作业拒绝发布、活动租约／ACL／来源账号保留及零抽目录失效通过，测试实例已停止。
- 本地测试阶段补齐中文“继承中…”词条，并核对真实账号的 schema 3 继承历史还原及服务端／浏览器目录指纹一致。

同机合成基准使用 40 池与 1 千／1 万／5 万条历史。5 万条构建由约 777 ms 降至 349 ms，完整继承 JSON 由约 5.63 MB 降至 4.04 MB；账本读取由约 47 ms 降至约 0.004 ms。千条构建约 24 ms，与旧版基本持平。此基准用于比较计算及未压缩载荷，不表示实际网络延迟；复跑入口为 `scripts/benchmark-simulator.mjs`。

真实密码／OAuth 登录、官方记录获取、邮件投递、开奖和生产用户历史写入需要各自环境及操作验证，本次未执行。移动模拟器仍提示使用桌面版，首次指南仍是开发预览，未作为新增完整功能发布。

## 发布要求

版本 PR 合入后检查 CI、目标部署与正式域名。站点优先显示 `site_config.site_version`，应用包版本只作默认值；发布时同步运行时 `site_version`、`build_info` 和公共缓存版本，再核对页面显示。

2026-10-09 按维护者授权，已在现有自托管数据库备份个人分析状态／快照并事务应用 `2026100901_simulator_inheritance_v2.sql`，通过临时 schema 3 Worker 重建快照供本地测试。浏览器写入权限保持封闭，迁移不改真实抽卡历史。该数据库不要重复执行本次失效迁移；其他已有环境仍需应用迁移，新环境使用完整 baseline，不重复叠加其中迁移。

正式主站与常驻 Worker 尚未随此次数据库操作发布。常驻 Worker 必须更新为 schema 3，才能持续处理之后的历史变更；发布与就绪验证按 [模拟器部署合同](SIMULATOR_ENGINE.md#验证与部署) 执行。历史日期／赠送存量修复不重复执行，独立日历、记录获取后端与邮件服务器不从主站包版本推定升级。
