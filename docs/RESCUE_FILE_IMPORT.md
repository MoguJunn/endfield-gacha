# 第三方历史记录迁入

在桌面或手机的「文件导入」中选择对应来源，上传原文件，核对账号、区服和预览后保存。当前说明包含 2026-10-17 已上线修复；保存进度、中断后继续及数量核对见 [文件导入、去重与失败恢复](FILE_IMPORT_RELIABILITY.md)。

## endgacha.kwer.top

- 支持校验 JSON、纯寻访 JSON 和纯寻访 TXT。校验 JSON 读取账号、渠道及原始序号；纯文件没有账号信息，需要在预览中确定归属。携带校验字段不表示本站已验证来源签名。
- B 服与官服分别识别；TXT 缺少卡池 ID 时按目录中的唯一同名条目匹配，同名歧义时提示核对。
- 保存前核对服务器完整明细，支持重复文件及跨 JSON／TXT 导入。按数量逐条匹配相同批次，顺序相反不会再累计一份，同一十连内重复物品的真实数量仍保留。
- TXT 可包含第四段免费标记；缺少时保留来源未提供这一事实，匹配已有记录时不覆盖其免费或特殊获取属性。本站 TXT 导出保留免费标记。
- 以服务器确认保存完成为准；若中途失败，预览会保留，再次确认可继续缺少的部分。原来已经写入的重复记录不由导入器自动清理。

## 终末地小助手（现蓝色星原小助手）难民收留处

- 支持带 UID 行，以及「抽卡时间、卡池ID、获得内容、抽取序列ID、星级、角色/武器ID、间隔抽数」等表头的 XLSX；按表头识别，不要求特定文件名或导出日期。
- 需要登录，并选择实际游戏区服；表内没有区服时不会默认写入国服。
- 只保存已知五星、六星结果和明确的六星出货间隔。「免费十连／未出货」作为免费十连摘要保存，不生成名为“未出货”的角色。
- 高星资料保存为个人补录，不参加全服统计。缺失的低星、总抽数、累计位置与起始垫抽保持未知。
- 原表时间与卡池日历不一致，或间隔超过本池保底上限时，预览会提示。原值保留在来源说明中待核对，暂不用于对应的精确分析。

仅列出各卡池抽数、出货数和总计的“抽卡分析”Excel，与带时间和具名结果的高星摘要不同。没有受支持的记录表头时，导入器明确提示，不再生成 0 条空预览；只有汇总数字的资料可在工作台手动补录已知量，不能还原为逐条历史。带大量空样式单元格的工作表会跳过空单元格，避免解析时反复扫描整张表。

## 离愁轩 Wiki 难民收留处

- 支持 `wiki.lcx.cab/zmd/gacha_tracker.php` 导出的 `{code:0,data:{uid,serverId,total,list}}` 文件，包含 JSON、TXT 和无扩展名文件，无需改名。
- 使用文件中的账号、区服、原始寻访序号、时间和免费标记；B 服单独保留为 B 服。按名称、星级及类型匹配本站目录，原站数字角色／武器 ID 不作为官方 ID 使用，具名记录缺少 ID 时也可匹配。
- 兼容武器旧名“应急手段”与现名“显锋”。具名结果使用本站目录星级，兼容原站通用模板少一星的写法；已经正确的四／五／六星不整体升星。
- 先核对原始声明条数，再按卡池和序号核对重复。名称规范后实体、时间、星级、免费标记均一致的重复只保留一次；同一序号内容冲突、目录匹配歧义或条数不一致时仍提示错误。
- 原站通用模板中的“三星未知角色／武器”按终末地四星结果保存，显示专用未知四星占位，保留时间、序号和免费标记，正常计入抽数、四星数量与保底。不会将其指定为某个角色或武器，不会伪造首次获得或潜能。
- 文件能证明该次未知角色出现前所有四星角色均已满潜时，按满潜重复计算其收益；不能证明时只保留四星寻访，不推断具体角色的收益。四星占位数量在导入预览中明确提示。
- 已导入旧版具名明细的账号可重新导入原文件，正常去重后只补入缺少的占位记录；再次导入不会重复累计。无需先删掉已有数据。

## 重复文件

登录后保存文件前读取当前网站用户的完整服务端明细，按区服、UID、卡池及原序号跳过已存记录；缺序号的 kwer 文件再做受限的同批内容匹配。不能只靠本机已加载的部分历史去重。Excel 补录会对照原有明细和已保存补录，按实体、原表时间及抽取方式逐次匹配，保留同一十连中重复获得同一物品的实际数量。相同范围的改名文件或重复导出不会重新累计。

新的高星结果只合并到兼容的、不完整的文件补录中，使用原条目的修订号进行服务端校验。遇到完整汇总或不兼容的覆盖范围冲突时，保留预览，提示到数据工作台核对。

所有补录继续经过数据工作台的校验和原子提交接口；没有校验令牌或修订发生变化时不能提交。明细与补录不是整份文件的单个事务，前面成功的批次可能已经保存；失败后保留预览，重试重新核对已有内容。

文件预览在当前标签页默认保留 30 分钟，原文件请自行保存。预览条数、账号明细条数与当前总览筛选的抽数口径分别核对；不要为解决一次中断而直接删除全部数据。详细边界见 [恢复说明](FILE_IMPORT_RELIABILITY.md)。
