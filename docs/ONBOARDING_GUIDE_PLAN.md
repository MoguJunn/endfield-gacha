# 首次使用指南设计

目标是让首次访问、已登录未导入和已有记录的用户都能找到下一步。教程与首页指南共享步骤、术语和操作入口，首页可随时重新查看。

## 当前进度

`/statistics-preview.html` 已提供游客、无记录、已有数据和导入待核对四种样例。该入口只在 Vite DEV 中渲染，按钮解释动作但不执行登录、导入或备份；真实业务接入尚未完成。

## 用户流程

1. 登录或了解如何导入。
2. 导入记录，查看结果与必要的异常提醒。
3. 选择账号和卡池，区分个人分析与全服统计。
4. 查看分析，并按需导出备份。

步骤完成依据真实账号、导入、同步和备份状态，不以本地勾选模拟成功。未完成和失败步骤提供恢复动作；老用户可跳过或关闭，新用户也能继续正常操作。

## 实现要求

- 复用现有认证、导入和分析服务，沿用 [桌面布局](DESKTOP_HOME_DEMO.md) 的指南弹窗入口。
- 核心操作支持键盘和触摸，不依赖拖拽或悬停才能发现。
- 中英文、亮暗主题、减少动态效果和手机阅读保持一致。
- 尚未发布的手动补录功能不出现在正式指南；官方版本导览也不作为本站导入或备份完成条件。

## 验证范围

覆盖首次访问、跳过、重看、登录无记录、导入成功／失败、账号切换及清除教程偏好。新用户应能沿教程完成一次导入并进入个人分析，首页指南与教程内容一致，任何状态都不阻挡正常使用。
