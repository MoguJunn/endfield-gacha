# ONBOARDING-GUIDE-001：首次使用教程与首页指南优化

Last reviewed: 2026-09-05

## 状态与目标

P1，待开始。本任务由用户在桌面 Demo 验收后提出：“增加新任务，优化首次使用的教程和首页的指南。”本次只登记任务，尚未设计或实现教程改动。

让首次访问、已登录未导入和已有记录的用户，都能看懂当前可做的下一步，并能从首页随时重新查阅指南。首次使用教程与首页指南复用同一套步骤、术语和操作入口。

## 工作范围

- 核对现有首次使用教程、首页指南和登录 / 导入 / 分析入口，找出过时内容、重复说明和无法继续的步骤。
- 围绕“登录 → 导入记录 → 选择账号与卡池 → 查看个人分析 → 导出备份”整理简短流程；常见问题按需展开，明确个人分析与全服统计的区别。
- 根据真实登录和数据状态提供下一步入口；步骤完成条件复用既有账号 / 数据状态，不以本地勾选代替导入或同步完成。
- 支持跳过、关闭和重新查看；保留正常操作路径，不强迫老用户重复教程，不使用只能拖动或悬停才能发现的核心操作。
- 对齐中英文、亮暗主题、键盘、减少动态效果和移动端阅读。桌面遵循已验收的 1366×768 首页及指南弹窗结构，详细说明在指南中展开。

## 与既有任务的关系

- `UX-011` 负责首次使用任务清单及完成条件；本任务负责教程与首页指南的内容、呈现和操作衔接，复用同一状态定义。
- `NAV-UX-001` 负责任务导航，`DESKTOP-HOME-001` 提供已验收的桌面布局；本任务沿用这些入口，不重新设计首页总体布局。
- 导入、认证和统计业务合同保持既有权威来源；若发现独立业务故障，另行记录，不在教程中伪造成功状态。

## 下一步与验收

1. 盘点真实教程 / 指南入口，明确三类用户状态、推荐步骤和可继续动作。
2. 形成简短内容大纲与桌面 / 移动呈现方案，再实现复用的指南内容。
3. 验证首次访问、跳过、重看、登录后无记录、导入成功 / 失败、账号切换和清除本地教程偏好后的行为。

验收要求：新用户可沿教程完成一次导入并进入个人分析；未完成或失败步骤有清楚的恢复动作；首页指南可随时重看且与教程一致；正常使用不被教程阻挡；中英文、键盘及移动阅读没有关键阻断。
