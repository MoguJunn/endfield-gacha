# 官方导入、扫码与任务恢复

本文说明 v4.7.1 的使用行为。官方记录由独立 CN／INTL 后端获取并保存；第三方文件走另一条分批保存流程，见 [文件导入](FILE_IMPORT_RELIABILITY.md)。

## 选择导入方式

| 方式 | 可用来源 | 操作 |
| --- | --- | --- |
| 扫码 | 国服 | 先登录本站，获取二维码，用页面列出的官方应用扫码并确认，再选择角色与区服 |
| Token | 国服／国际服 | 在对应官方账号入口取得当前 Token，粘贴到导入窗口，读取绑定角色并选择 |
| 文件 | 网站支持的导出格式 | 上传原始文件，核对 UID、区服和识别结果；不使用官方抓取任务 |

导入前确认本站账号，再核对游戏角色、游戏 UID、官服／B 服或国际区服。平台账号 UID 与游戏 UID 不同；没有游戏角色时不应继续导入。相同游戏 UID 也不能跨区服归并。

## 扫码生命周期

二维码等待时间为 2 分钟；手机确认并成功读取角色后，选角会话保留 10 分钟。轮询最小间隔 2 秒。取消、重新获取、离开页面或会话到期会清理旧扫码会话；创建新二维码也会替换当前用户旧会话。未完成会话只保存在国服后端进程内，服务重启后需要重新扫码。

浏览器仅保存本站随机设备标识，用于保持本次官方认证链的设备上下文，不保存官方登录 Token。它不表示登录状态，不跨网站共享，也不提供“长期记住官方账号”。清除网站存储会重新生成标识；存储不可用时仅在当前页面内保留。

官方凭据留在后端，选择角色后随导入任务加密交接；浏览器提交的是短期会话 ID。任务执行时会重新核对选中角色及区服，角色列表变化会停止导入并要求重新确认。关闭二维码或退出本站不等于官方账号退出，也不撤销其他设备授权。

## 导入进度与完成

1. 通过本站鉴权后创建后台任务，保留返回的任务 ID 与来源区服。
2. 轮询持久任务状态，等待认证、抓取、规范化、暂存及正式提交；HTTP 202 只表示已受理。
3. 后端自动核对完整分页与记录身份，并在一个数据库事务中保存正式历史及成功收据。客户端不再手动确认每条官方记录。
4. 成功后刷新当前账号清单、异常提醒与个人分析。分析快照可能仍在后台构建，抓取成功不等于所有图表已经重算。

默认增量导入只处理需要更新的记录，全量模式重新核对官方可提供范围；两者都不能找回官方源已不可提供且本站从未保存的历史。情报书、赠礼等非寻访事件不计入正常抽数；可定位的未知物品会提示核对，缺少安全归属的记录跳过，不能用占位值编造真实对象。

## 异常与恢复

- **本站登录过期**：恢复本站认证后继续查询已有任务；不要仅因网络错误清空用户状态。二维码失效则重新扫码。
- **已存在任务／队列繁忙**：优先继续查询服务端返回的既有任务，不重复并发创建。满队列时稍后再试。
- **进度查询中断**：网络超时不代表任务已失败或取消；恢复连接后先查原任务最终状态。当前客户端总等待期限为 30 分钟，后端也有任务期限与租约。
- **后端暂时不可用**：健康接口 HTTP 200 还需结合 `fullImport` 判断完整导入是否就绪；跨区转发另检查实际连通性，不靠更换同一份 Token 排除网络故障。
- **提交后提示目录整理警告**：正式保存收据与后处理警告分别显示，不能把已经保存的历史当成未保存再次覆盖。
- **需要取消**：后端支持提交前取消；正式提交开始后可能返回冲突，仍须等最终结果。关闭窗口或取消浏览器请求不能当作后端任务已取消。

不要为验证问题反复删除或重放真实历史。反馈时提供导入来源、发生时间、任务阶段、脱敏错误码及同范围数量；不公开 Token、扫码 URL、会话 ID 或用户导出。

## 开发入口与权限

扫码 UI 位于 `src/features/import/components/OfficialQrLogin.jsx`，控制器位于 `useOfficialImportController.js`，请求与设备标识位于 `src/utils/endfieldAuthChain.js` 和 `officialQrDevice.js`。这些入口与 Token 导入复用同一个导入任务和完成策略。

公开仓库不包含完整抓取服务。开发者 `public.read` Key、官方 BOT Key 和用户登录凭据各有权限范围，不能相互替代；新客户端需要维护者提供独立后端地址、允许的浏览器来源及私有接口说明，不能从公开分析 API 推导任意用户导入权限。

发布验证记录见 [v4.7.1](RELEASE_4.7.1.md)。自动化、浏览器替身和线上游客拒绝检查不等于已经用真实用户完成扫码、登录或历史写入。
