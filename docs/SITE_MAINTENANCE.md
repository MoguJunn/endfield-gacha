# 维护模式与通知横幅

超级管理员在“后台管理 → 站点配置 → 维护模式与横幅”中配置：

- 开启／关闭维护模式。
- 展示／隐藏受影响服务明细，并勾选本次涉及的服务范围。
- 允许／禁止用户收起横幅；收起后仍显示维护标题和时间。
- 编辑中英文标题、时间说明和正文，并在保存前预览。

配置通过现有超级管理员站点配置接口一次保存到 `site_config.site_maintenance_notice`，不是浏览器本地开关。保存成功后当前页面立即更新，其他可见页面约1～2分钟更新；隐藏标签页恢复可见时检查。失败会保留编辑内容并明确提示，不能将保存失败当作启用成功。贡献者沙盒仍通过自己的配置适配器保存，不触及生产配置。

横幅覆盖桌面、手机以及访问验证页面。该模式说明服务状态，不主动禁用登录、导入或其他路由；可用页面与本地功能继续保留。维护范围是展示用分类，不是各服务的停机开关。

## 本次数据库升级通知

时间为“即刻起，至升级完成”，不填写未经确认的恢复时刻。范围包括账号注册／登录／验证／恢复与绑定、云端记录与工作台、官方与文件导入保存、个人和全服统计、云存档、工单／公告／后台，以及数据库相关API、机器人和关联服务。

正文提示数据库依赖功能可能出现加载缓慢、请求失败或暂时无法访问，属于维护期间正常现象；建议稍后重试、避免反复提交。

## 数据库暂停时如何展示

`/api/maintenance` 只公开规范化后的通知字段，只允许读取，管理员保存继续走既有权限验证。它读取单个配置键，4秒数据库预算，同一实例合并并发并缓存1分钟，失败也间隔1分钟再读；CDN最多缓存30秒。浏览器每分钟在页面可见时检查，无重复重试。

数据库读取失败时保留服务器或浏览器最后一次成功状态（包括明确关闭）。首次访问且没有缓存时，使用随部署附带的本次数据库升级通知，避免数据库停机连维护说明都无法展示。该部署内通知在 `shared/siteMaintenance.js`；**升级完成时先在后台关闭维护模式，并在后续发布中将部署默认 `enabled` 改为false**，以免未来数据库故障时无缓存新访客仍看到这次升级说明。数据库不可用时管理员保存同样可能不可用，请在停机前完成配置。

本功能没有新增数据库表或迁移，不修改用户记录，也不会执行服务器升级、重启或停机。
