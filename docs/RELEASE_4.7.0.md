# v4.7.0 发布记录

代码版本为 `4.7.0`，界面版本为 `v4.7.0`，构建标识为 `Build 2026.10.31`。本次发布汇总导入修复、个人统计、手机首页、时间线分享及缓存改进。

## 功能与修复

- 手机正式首页复用新版首页模块，并适配纵向浏览、窄屏与触控；版本、日程、公告和社区入口保持可用。
- 个人概览新增手气评价与抽卡高光，按账号展示角色／武器结果；历史精度不足时保留未知状态，评价合同见 [个人手气](PERSONAL_LUCK.md)。
- 新增限定与复刻合并 UP 均抽；个人单池、合池、概览拆分和时间线的不歪率统一剔除 120 抽保障，不改变出货总数与原始记录。
- 分享图使用当前时间线排序、卡池筛选、卡片／瀑布流模式及五星显示设置，补充保障、继承保底、武器十连与出货时间；生成图缓存纳入这些展示选项。
- 改进第三方 Excel 解析，避免部分分析表空导入及样式单元格卡顿；会话恢复保留导入预览，官方导入提前校验游戏 UID。
- 修复桌面／手机卡池分类折叠，增加比例导航；卡池开放后自动清理“前瞻”名称，并校正相关版本时间。
- 公共目录和统计持久保存到浏览器，合并同时触发的版本检查；个人分析与统计按快照修订更新，公开导入队列不会引发持续前台轮询。

## 数据库与后台准备

本次代码相对上一主线新增四项迁移，新环境直接使用包含 **215 项迁移**的完整 baseline；已有环境只执行尚未应用的前向迁移。

1. `2026103001_clear_opened_pool_preview_labels.sql`：清理已开池的前瞻名称及失效公共目录缓存。
2. `2026103100_personal_win_rate_guarantee.sql`：个人分析切换至 schema 6，并标记旧结果重建；已执行环境不得重复触发失效。
3. `2026103101_backfill_personal_luck.sql`：仅服务角色可使用的手气补算读取与发布 RPC，带修订、活动租约和重复发布保护。
4. `2026103102_release_470.sql`：同步运行版本、构建信息、中英文公告和公共缓存版本；固定公告 ID 避免重复公告。

生产数据库在本次合并前已完成前三项准备，个人分析与统计 Worker 已分别更新。手气补算在服务器读取历史并计算，只合并 `luck`，保留其他统计字段和原计算时间，同时推进快照修订以失效浏览器缓存。补算时限制每页元数据范围，避免先扫描全部大 JSON。

2026-10-31 的独立核验覆盖 4,581 份个人统计快照，缺少手气字段为 0；其中有历史的 3,057 份全部覆盖，空账号 1,524 份。个人分析 owner／scope 待处理与错误均为 0，常规 Worker 定时器已恢复。上述数字是当时结果，后续用户数据变化仍会产生任务。操作、限制和验证见 [统计调度](STATISTICS_SCHEDULING.md)。

## 发布与回退

发布使用当前主题分支的新 PR 合入 `main`，等待 CI 与 Vercel 检查后合并；GitHub-connected Vercel 随 main 更新生产部署。本地 main 随远端合并提交快进，其他工作树的未提交资料保留。

公告与运行版本发布前，在数据库服务器备份原公告及相关配置；公告发布不删除历史。发布后核对两个正式域名的运行版本、双语正文、公共接口和移动首页。个人分析已使用同机 schema 6 Worker，本次不覆盖既有同机调度方式。

需要回退时通过新的 revert 提交恢复应用代码，按远端备份恢复运行配置或停用本次公告；不回滚用户历史、不重复执行个人分析失效迁移。版本元数据的恢复和代码回退应保持一致。
