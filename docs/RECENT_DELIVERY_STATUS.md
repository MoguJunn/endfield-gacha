# 项目进展与已知限制

当前仓库准备 **v4.6.4**，构建标识 `Build 2026.10.09`，包含仓库整理、公开文档与本地预览统计修复。上一正式发布为 v4.6.3；4.6.4 尚待版本 PR 合入及部署，线上状态以实际站点为准。

## 4.6.4 更新准备

- 隐藏访问验证中的旧版验证按钮，保留内部验证码实现。
- 本地 API 环境按项目目录加载，修复从其他目录启动预览时统计读取失败。
- 贡献者沙盒支持单池、五类合池与个人统计，使用本地演示历史并隔离真实写入。
- 合并配置、移除已废弃入口与一次性报告，并按用户／贡献者用途整理公开说明。

变化、验证与发布要求见 [v4.6.4 说明](RELEASE_4.6.4.md)。

## 近期可用功能

- **新版桌面**：默认首页与经典版切换、统一消息弹窗、个人／全服统计分区及响应式宽度。
- **统计**：单池与五类合池、十图、头像选择和分类排序；公共与个人统计读取后台生成的快照，展示真实计算时间。
- **官方导入**：支持重构期次，改善已有卡池写入；情报书和信物赠送不会计入寻访抽数或保底。
- **首页与日历**：官方版本导览、官网封面、限定武器池同期角色关联与第三期截止时间工具；独立日历读取数据库日期并区分重构系列／期次。
- **管理体验**：目录保存复用统计计数，后台刷新更好地处理浏览器认证锁竞争，已有角色与武器可补充头像。

变化与来源见 [v4.6.2](RELEASE_4.6.2.md)、[v4.6.3](RELEASE_4.6.3.md) 发布记录。

## 数据解释与限制

导入记录可能不完整，统计中的“首次”表示已保存的本期记录内首次。特定角色或武器的首获成本与任意六星硬保底是不同概念，不能把所有超过 80 的对象首获统一截断。混合格式导入的重复记录修正仍在改进中，指标定义见 [统计合同](STATS_OBSERVATION_CONTRACT.md)。

活动日期与奖励条件采用官方来源。数据库明确空日期不会由备份补齐；已打开的日历页面和 CDN 可能暂时保留旧响应，诊断方式见 [卡池时间管理](POOL_SCHEDULE_MANAGEMENT.md)。

本仓库提供主站和共享数据合同；独立日历、记录获取后端和邮件服务器有各自的部署要求，不能从主站版本推定它们的运行状态。
