# 移动首页现状与后续方向

共享新版手机首页已随 v4.7.0 正式发布，当前入口为 `src/mobile/views/MobileHomeView.jsx`，在独立纵向滚动容器中复用 `DesktopHomeDemo mobile`。本文保留内容与交互要求，并区分已发布范围和后续验证；不再将整个手机首页标为尚未实现。发布证据见 [v4.7.0](RELEASE_4.7.0.md)。

## 首版内容顺序

1. 精简页头与主操作：未登录显示登录／导入入口，已登录显示个人概览和继续导入。复用现有认证和导入流程。
2. 当前寻访：角色、武器、重构卡池分组展示，保留剩余时间与阵容。首屏突出当前池，更多卡池横向切换，不阻止纵向滑动。
3. 版本与轮换：近期版本节点、下一期轮换；未知日期明确显示待公布，避免大面积空白和无效倒计时。
4. 社区动态：有活动时展示活动及真实状态；结束后显示活动回顾、全服观测、交流反馈入口。不编造下一场活动日期、获奖结果或参与人数。
5. 公告和常用工具：合并消息入口，提供机制、模拟器、使用指南与支持。长说明移入二级页，首页留短摘要。

## 实施范围与入口

- 当前正式页：`src/mobile/views/MobileHomeView.jsx` 和 `mobileHome.css`，由 `MobileLayout.jsx` 加载；保留底部导航与手机路由。旧 `MobileHomePageView.jsx` 不再是正式首页入口。
- `HomeLandingDemo mobile` 只作为开发预览；正式页复用共享业务模块，并使用手机纵向布局。
- 复用现有卡池日程、版本配置、公告、主题与中英文能力，不增加新数据库表或独立首页数据源。
- 社区活动复用 `CommunityActivitySection`，本期活动窗口默认显示 `RegulationLotteryCard`，截止后隐藏推广；社区与版本页仍可切换。站内功能使用手机路由，独立抽奖页使用同源 `/lottery/`。

## 验收标准

- 360、390、430 像素宽度及横屏可正常浏览，无页面横向溢出；手机首页允许自然下滑，不套用桌面一屏展示约束。
- 只保留一个主纵向滚动容器；触摸从文字、卡片、横向列表上开始都能向下浏览，底部安全区不遮挡最后一个操作。
- 首屏能找到登录／个人分析和当前寻访；点击卡片、公告、工具后可正常返回，保留合理的滚动位置。
- 中英文、亮暗主题、减少动态效果、空数据／加载／失败／已结束活动状态均可读。
- 用浏览器手机触摸模拟验证滚动、导航与布局；正式启用前再检查真实手机 Safari／Chrome。
