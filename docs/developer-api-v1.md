# Public Analytics API v1

This entry points to the maintained bilingual API documentation:

- [简体中文](developer-api-v1.zh-CN.md)
- [English](developer-api-v1.en-US.md)

The in-app wiki is available at `/developer-api` after a developer application is approved. The public API covers read-only catalog data and anonymous aggregate analytics; private user data is outside its `public.read` scope.

The former duplicated endpoint reference has been retired to prevent drift. Authentication, pagination, cache behavior and endpoint fields are maintained in the two documents above. Controlled account binding and official bot queries are documented separately in [integration-api.md](integration-api.md).
