## 原整合范围

当时把 `feat/data-workbench` 的工作台代码接入主站工作区，供本机查看主站导航、账号选择、导入及修改的效果；2026-10-14 已执行生产数据库迁移并升级后台计算，执行状态见下文。

- 桌面：`/data-workbench`，新版个人卡池分析导航增加「导入／修改」。
- 手机：`/m/data-workbench`，抽屉及卡池页导入入口接入。
- 问卷、截图识别、转换文件沿用已验收的工作台组件；未开放卡池限制、删除确认、五星折叠及截图滚动修复一并接入。
- 合并时保留主站现有首页、武器同期池关联、完整名单数据库读取、模拟器继承投影及定时统计读取。
- 手机有待保存内容时，通知入口上移，避免挡住保存按钮。

## 本机体验

从主仓库运行：

```powershell
node scripts/preview-workbench-integration.mjs
```

桌面地址 `http://127.0.0.1:5186/data-workbench`，手机布局地址 `http://127.0.0.1:5186/m/data-workbench`。脚本读取现有 `_demos/workbench-feedback/snapshot.json`，含四个脱敏账号、2108 条历史和完整卡池名单。支持另外填写空白游戏账号。

该专用脚本仅在开发服务器中注入测试身份及内存接口，阻止生产 API 和认证请求；保存只在该服务器内存生效，重启服务后恢复初始记录。它关闭本次预览的问卷等待时间，正式组件仍默认 15 秒。

## 增量版本与真实账号预览

工作台新增「修改记录」入口，支持预览影响后撤回最近 180 天内的最近 5 次修改。撤回本身也生成版本，可以恢复刚才的撤回。数据库保留一份当前数据，仅将业务变化字段和数组元素写入版本增量，并压缩已使用的保存校验副本。

本轮真实账号预览已启动在 `http://127.0.0.1:5189/data-workbench`，手机布局为 `http://127.0.0.1:5189/m/data-workbench`，含 4 个真实游戏账号、2108 条历史。这个模式使用本机临时 PostgreSQL 执行实际迁移、原子保存和撤回；刷新保留本机修改，停止服务后清理数据库。线上账号只用于读取初始数据。

数据库结构、保留范围、并发处理、迁移依赖及重启命令见 [抽卡数据增量版本与撤回](ACCOUNT_DATA_REVISIONS.md)。该数据库模式与上方脱敏内存预览分别运行。
