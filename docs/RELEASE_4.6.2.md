# v4.6.2 发布准备

状态核对：2026-09-24。官方重构适配 PR #35 与导入超时修复 PR #38 已合并；统计 PR #34 提前上线后因数据库未就绪返回 503，已由 PR #36 恢复。恢复 PR #37 来自 `release/4.6.2-statistics-ready`，生产数据库备份、迁移、独立 Worker 与全部3,942个 `public-statistics-v4` 快照已就绪，待最终合并 CI 后发布读端。

## 交付范围

- 单池与五类合池：限定角色、限定武器、常驻武器、重构寻访、重构申领。常驻角色、启程与辉光庆典不进入合池。
- 首次样本先逐账号、逐期、逐对象计算，再按对象当期身份汇总为目标、其他限定、常驻与待分类六星；首次不跨期，类别不作为虚拟物品。账号覆盖按完整账号身份跨期去重，样本数与账号数分别解释。
- 对于共用卡池 ID 的官方重构记录，观测成本时间线再按 `pool_version` 分组；缺失期次保留独立未知期次组，不推测归属，也不增加账号覆盖数。保底与资源仍沿用原有跨期规则。
- PR #38 避免已有卡池的零行插入触发目录全量刷新，并补齐安全更新条件，保留真实数据库错误提示。迁移196/197已由导入修复任务部署；统计迁移源同步保留安全更新条件，避免新环境安装顺序覆盖修复。
- 旧 `metrics` / `resources` 按选择的单池或合池迁入快照。保底间隔与资源拷贝顺序仍使用完整相关账号上下文；`resultsPerTarget` 不解释为首获均值，未知身份与未知成本不填零。
- 统计工作区提供十图（原八图加账号覆盖、花费区间）、目标速览、头像对象选择、分类及拼音排序、分位数读数、频数分组、深色主题与减少动态效果。
- 全服和个人统计只读持久结果，5/30/60 分钟队列按受影响范围重算；成员变化、修订冲突与读取不完整不会发布不完整结果。首次未就绪显示等待，已有结果保留真实计算时间。
- 各桌面页面、顶栏与底栏统一沿用首页响应式宽度，覆盖经典入口及长内容页。首页无需纵向下滑的合同不扩展到长统计或设置页。
- 首次使用指南仅在 `/statistics-preview.html` 开发预览中提供状态样例，未接入真实登录、导入、备份或完成状态，不作为已上线功能宣传。

统计口径见 [STATS_OBSERVATION_CONTRACT.md](STATS_OBSERVATION_CONTRACT.md)，运行方式见 [STATISTICS_SCHEDULING.md](STATISTICS_SCHEDULING.md)，布局合同见 [DESKTOP_HOME_DEMO.md](DESKTOP_HOME_DEMO.md)。v4.6.0 及更早的发布记录继续保留其历史含义；独立后端与第三方依赖沿用各自版本。

## 已有验证

以下是本版本已完成的最终本地验证，仍不替代合入 main 后的 CI 与生产证据：

- 算法优化后全量单元测试 269 个文件、1,498 项通过，改动 ESLint 与主应用构建通过；优化前完整 ESLint、主应用与抽奖子应用构建及 1,495 项测试通过。
- 恢复候选275文件／1535项单测通过；合并 PR #38 后导入错误3项回归通过，PGlite统计 SQL（含197与统计安装顺序）和190迁移基线通过。生产读取处理器验证34单池、5合池、3旧统计、卡池计数返回200，匿名个人请求401；平台预览有登录保护，未将302误报为应用验证成功。
- 生产依赖安全审计：内部镜像不支持 `npm audit`，改用官方 registry 执行 `npm audit --omit=dev --audit-level=high --registry=https://registry.npmjs.org`，结果为 0 漏洞。
- 真实浏览器已检查桌面 1366～3840 宽度、合池 360～1920 宽度，以及对象选择、排序、图表、亮暗主题、减少动态效果和移动统计入口。
- 最大限定角色合池：1,009,281 个有效结果、2,675 个去重账号，独立任务约 70 秒，匿名响应约 96.5 KB。批量本地预览涵盖 34 单池、5 合池及 3 份旧缓存；这些观测不是生产性能承诺。
- 优化后用同一批 1,985,909 条真实记录核对新旧算法，34 单池＋5 合池全部字段一致。独立任务最大限定合池峰值 733MiB，连续五组合池进程峰值 810MiB；24 万条合成记录／72 范围的观测和旧指标峰值分别从 491／471MiB 降到 290／184MiB，详见调度说明。
