# v4.6.2 发布记录

统计更新于 2026-09-24 经 [PR #37](https://github.com/MoguJunn/endfield-gacha/pull/37) 合入，提交 `8884cabe`。前次发布因数据库未就绪暂时回退，完成迁移、Worker 与首次快照预热后恢复；这确立了统计部署先准备计算、再启用读端的顺序。

## 功能变化

- 提供单池和五类合池：限定角色、限定武器、常驻武器、重构寻访、重构申领。
- 增加十图、头像选择、分类／拼音排序、分位数和区间读数，支持深色与减少动态效果。
- 首次按账号、期次、对象计算后再汇总类别；账号覆盖跨期去重，样本数与账号数分开解释。
- 官方重构共用池 ID 时再按 `pool_version` 分组，缺失期次保持未知；保底和资源沿用各自跨期规则。
- 旧指标与资源跟随选择范围读取快照，未知身份和成本不填零，`resultsPerTarget` 不表示首获均值。
- 全服与个人统计只读持久结果，展示计算时间；首次未就绪显示等待，成员变化、修订冲突或不完整读取不发布结果。
- 顶栏、正文与底栏统一响应式宽度，包含经典桌面入口和长内容页。

常驻角色、启程和辉光庆典不进入合池。首次指南只提供开发样例，真实操作尚未接入。

## 配套修复

PR #35 提供官方重构适配，PR #38 改善导入写入超时：已有卡池不触发无效插入及目录全量刷新，补齐安全更新条件。迁移与统计安装顺序保留同一合同，避免后执行的脚本覆盖修复。

## 发布验证

发布候选通过 275 个文件／1,535 项测试、ESLint、主站和抽奖构建，以及统计 SQL 和 baseline 校验。浏览器检查覆盖桌面 1366～3840、统计工作区 360～1920 宽度，包含筛选、对象选择、主题、动效和手机入口。

首次生成 3,942 个计算版本 `public-statistics-v4` 快照后恢复读端。公开 34 单池、5 合池、旧统计和计数处理器返回成功，匿名个人请求被拒绝；RLS 检查确认普通角色不能直接访问私有快照表或 RPC。

同一批 1,985,909 条记录的新旧算法对照覆盖 34 单池与 5 合池，结果字段一致。耗时和内存取决于数据规模及机器配置，首次预热通过不构成长期性能承诺。

这些结果属于发布时点，持续运行时应观察队列延迟、任务耗时、错误与资源占用。
